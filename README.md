# Icons

We use [Tabler Icons](https://tabler.io/icons), so you can find the icon you need on their website.

To use icons add `tio-` prefix to the icon name. By default, only outlined icons are available.

## How to start local development

Simply install [Nix](https://nixos.org/download.html) and run the following command:

```bash
nix develop
```
