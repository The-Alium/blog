On September 16, a planned update for Garry's Mod was released, which had been announced in the community hub on September 9. In addition, a hotfix was added to the update on September 17 to fix game crashes.

The September update adds support for 64-bit binaries for developer tools such as Hammer Editor, which will help prevent crashes caused by the previous limitations of 32-bit systems.

The player model selection menu received a new visual design and themed categories for easier navigation. Subcategories were also added to the spawn lists, and a Downloads category was added to addons. A new NPC, the Broken Manhack, was added to the spawn lists. The Tools menu now includes an option to hide tools that have been blocked by the server.

Insurgency has been added to the game content officially supported in Garry's Mod.

Among the improvements, it is worth noting that the Combine Dropship NPC and Combine APC now take damage when used as vehicles. The size of NPC pupils now depends on the size of their model, and an asymmetric visual shrinking effect was added when using the Inflator Tool.

The update introduced the ability to add dupes, saves, and demos to favorites. The loading screen now displays more information about Workshop content being downloaded. In addition, the update includes improved player death checks to prevent NPCs from reacting to the player's death, along with many other fixes and improvements.
